# مولّد مقاطع القرآن القصيرة

أداة عربية 100% لصناعة Reels/Shorts للقرآن الكريم بضغطة زر واحدة. تقوم بجلب النص العثماني والصوت تلقائياً، ثم تركيب طبقات الفيديو (خلفية + نص + تلاوة) وإخراج فيديو طولي مناسب للهواتف بجودة عالية.

## وصف مختصر
تحدد السورة والآية والقارئ، وتختار مستوى الجودة، ثم تتابع شريط التقدم حتى يتم إخراج الفيديو النهائي بصيغة MP4 بدون تدخل يدوي إضافي.

## المميزات
- أتمتة كاملة لجلب النصوص والصوت.
- دعم لأكثر من 10 قرّاء.
- خلفيات ديناميكية عشوائية.
- تنسيق ذكي للنص على شاشة الجوال.
- دعم اللغة العربية والرسم العثماني.
- واجهة بسيطة للمبتدئين مع خيارات متقدمة للمحترفين.

## التشغيل السريع
```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python backend/app.py
```

ثم افتح المتصفح على: `http://localhost:5000`.

## التشغيل عبر npm
```bash
npm start
```

ثم افتح المتصفح على: `http://localhost:5000`.
> ملاحظة: ما زلت تحتاج لتثبيت متطلبات Python عبر `pip install -r requirements.txt`.

## ملاحظات
- ضع مقاطع فيديو الخلفيات داخل `assets/backgrounds` بصيغة `mp4`.
- تحتاج تثبيت خط عربي مثل Amiri لتظهر الكتابة بشكل جيد في الفيديو.
- مصادر النص والصوت المستخدمة مجانية ومفتوحة عبر:
  - `api.alquran.cloud` للنص العثماني.
  - `everyayah.com` للصوتيات.
- كل المكونات البرمجية المستخدمة هنا مفتوحة المصدر ومجانية بالكامل.
- يتطلب الخادم وجود FFmpeg مثبتاً على النظام لتوليد الفيديو.
- الواجهة تعرض شريط تقدم تلقائياً حتى اكتمال الفيديو.
- خيار الجودة `خفيف للأجهزة الضعيفة` يقلل الحمل على الأجهزة البطاطس مع الحفاظ على جودة مقبولة.
- المدة القصوى للصوت محددة بـ 10 دقائق لضمان إنتاج الفيديو خلال أقل من 10 دقائق.

## جاهزية النشر
المشروع جاهز للنشر مباشرة بعد تثبيت المتطلبات (Python + npm + FFmpeg)، ولا يتطلب أي تعديلات إضافية. يمكنك تشغيله كخدمة محلية أو على خادم خاص حسب الحاجة.
